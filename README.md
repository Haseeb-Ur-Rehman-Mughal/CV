# Professional CV - Hafiz Muhammad Aaqib

This is a modern, responsive CV created using HTML, CSS, and JavaScript. The CV features a clean two-column design with a professional black color scheme, Times New Roman font, and is formatted for A4 paper size for printing.

## Features

- A4 paper size format (210mm × 297mm)
- Two-column layout for efficient space usage
- Professional black text for optimal readability
- Times New Roman font for traditional professional appearance
- Proper profile image handling with fallback
- Print-friendly styling with no content cutting
- Responsive design for screen viewing
- Sections for:
  - Contact Information
  - Education
  - Professional Experience
  - Skills
  - Languages
  - Qualifications
  - Professional Profile

## Files Included

1. `index.html` - Main CV content structure
2. `styles.css` - All styling for the CV
3. `script.js` - Handles profile image and print functionality

## Usage

1. To use this CV:
   - Place your profile image named `profile.jpg` in the same directory (or the image fallback will be used)
   - Open `index.html` in a web browser to view
   - Use browser's print function (Ctrl+P / Cmd+P) to save as PDF

2. The CV is designed to print completely on A4 paper with no content cutting

## Customization

1. Edit `index.html` to update:
   - Personal information
   - Education details
   - Work experience
   - Skills and languages

2. Edit `styles.css` to modify:
   - Font size and typography
   - Spacing between elements
   - Section heights and layout

## Print Settings

For best results when printing to PDF:
- Use Chrome or Edge browser
- Set paper size to A4
- Set scale to 100%
- Enable background graphics
- Set margins to "None" or "Minimum"
- Do not enable headers and footers
